# FinSight frontend

Next.js (App Router) UI for the FinSight portfolio app.

See the **[root README](../README.md)** for architecture, setup, features, and limitations.

```bash
cp .env.example .env.local
npm install
npm run dev
```

Requires the API at `NEXT_PUBLIC_API_BASE_URL` (default `http://127.0.0.1:8000`).
